Weft 1.0.2 brings clearer setup, more relevant content search, and quieter background indexing.

### Highlights

- **Choose your language first:** 한국어, English, 简体中文, and 日本語 throughout setup, search, menus, and settings. Switch languages without reindexing.
- **Search document contents:** contentless FTS5 keyword search joins semantic and path evidence. Complete identifier matches such as `INV-2041` bypass model inference.
- **Fewer unrelated results:** cosine and query-adaptive relevance gates remove weak semantic hits. Results below half the best fused score are hidden. Queries such as `md` or `pdf` use exact extension lookup.
- **Quieter indexing:** a default 25% compute-time budget, smaller inference slices, and cooperative yielding to interactive searches. Indexing models are released during pauses and sustained searches.
- **Clearer desktop UX:** menu-bar progress, estimated remaining work, watching state, and failures; centered compact Word/PDF/Office previews; English, Chinese, and Japanese command aliases.
- **Consistent branding and documentation:** the README logo now uses the actual app icon, including its horizontal weave. New native UI GIFs and benchmark records show how search works.

### Benchmarks and verification

On the 26-file, 21-query development fixture, MRR@10 improved from 0.913 with legacy RRF to 0.976 with content fusion and relevance gates; Recall@10 remained 1.000. Fusion returned 1.57 results per query on average. Ranking-stage p50/p95 were 0.431/0.669 ms, excluding model loading, embedding, and process startup. This small fixture does not establish general accuracy or large-index latency.

The separately recorded M4 Pro snapshot comparison measured an 8.217 → 3.701 ms SIMD scan and an 80.500 MiB reduction in peak benchmark-process memory. These are different datasets and measured stages. Indexing GPU utilization and power were not measured; 25% is a compute-time budget.

Local Rust tests, hybrid CLI integration, native UI checks, translation coverage, and app signature validation passed. See the README and `eval/` reports for methodology and limitations.

### Downloads and compatibility

- **Apple Silicon:** `Weft-1.0.2-arm64.dmg`
- **Intel:** `Weft-1.0.2-x86_64.dmg`
- Architecture-specific ZIPs support the app updater. CLI archives are available for macOS Apple Silicon and Linux x86_64. `SHA256SUMS` contains asset checksums.
- macOS 14 or later. Desktop builds are ad hoc signed and are not Developer ID notarized. If macOS blocks launch, use System Settings → Privacy & Security → Open Anyway.
- Existing vectors are preserved. Content keyword postings are populated on the next explicit indexing pass; choosing a UI language does not start a scan.
- Chinese and Japanese semantic search passed a basic smoke check; mid-sentence keyword substring search still needs improvement.

### 한국어 안내

첫 실행에서 한국어·영어·중국어·일본어를 선택할 수 있습니다. 본문 키워드와 의미 검색을 결합하고, 관련도가 낮은 결과를 숨기도록 개선했습니다. 메뉴바에는 진행 상태와 남은 작업 추정·오류가 표시되며, Word 등 문서 미리보기도 중앙에 맞췄습니다. 배경 인덱싱은 기본 25% 작업 예산으로 동작하고 검색 중에는 양보합니다. 기존 인덱스를 다시 만들 필요는 없으며, 새 키워드 색인은 다음 명시적 인덱싱 때 추가됩니다.
